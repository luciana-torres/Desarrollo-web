Portafolio Web — Luciana Torres

Bienvenido/a al repositorio oficial de mi portafolio web personal y académico. Este proyecto reúne los avances desarrollados durante el curso de Desarrollo Web, con un enfoque en diseño responsivo, maquetación semántica y control de versiones mediante Git.

Sitio Desplegado

Podés acceder al sitio en vivo a través del siguiente enlace:
https://github.com/luciana-torres/Desarrollo-web

Características del Proyecto

Maquetación Semántica: HTML5 con jerarquía clara y etiquetas semánticas (header, main, section, article, footer).

Diseño Responsivo (Mobile-First): Vistas completamente adaptadas para dispositivos móviles, tablets y computadoras de escritorio.

Framework & Estilos: Uso de Bootstrap 5 (Navbar, Carousel, Grilla responsiva) combinado con un archivo styles.css propio para personalizar colores, tipografía y diseño general.

Estructura de Navegación (5 Páginas):

index.html (Página de inicio)

pages/sobre-mi.html (Perfil académico y personal)

pages/servicios.html (Tecnologías, lenguajes y habilidades)

pages/proyectos.html (Galería visual y listado de proyectos)

pages/contacto.html (Formulario e información de contacto)

Tecnologías y Herramientas Utilizadas

HTML5

CSS3 (Flexbox & CSS Grid)

Bootstrap 5.3

Git (Control de versiones desde consola)

GitHub & GitHub Pages (Alojamiento del código y despliegue del sitio)
